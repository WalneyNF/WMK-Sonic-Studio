🎼 WMK Music Bridge

Conexão prática entre WMK Maestro IA, MuseScore Studio e Suno

Compositor IA · Partituras · Provedores

Fluxo completo

1. Peça ao Maestro IA uma música e baixe o arquivo MIDI.

2. Abra o MIDI no MuseScore Studio para visualizar, editar ou imprimir a partitura.

3. Abra o mesmo MIDI no WMK Sonic Studio e escolha instrumentos virtuais (SF2/SFZ/VST3/CLAP).

4. Se desejar experimentar uma interpretação gerada por áudio, monte o prompt abaixo e copie para o Suno.

5. Importe na DAW o áudio que você obteve por download autorizado, respeitando a licença correspondente.

🎤 Criar prompt para Suno

Este gerador organiza sua ideia e não envia dados ao Suno. O site é aberto separadamente.

Abrir Suno

Preencha a descrição e clique em Preparar prompt.

Direitos: canções do plano gratuito Suno não possuem direitos comerciais. Consulte as regras de download e de uso antes de utilizar em um jogo publicado.

🎼 Conversão com MuseScore instalado

O módulo Python maestro/integracoes.py usa o executável instalado do MuseScore para converter partituras e arquivos MIDI. Exemplos para PowerShell:

py -3 maestro/integracoes.py converter "minha_musica.mid" "minha_partitura.musicxml"
py -3 maestro/integracoes.py converter "minha_musica.mid" "minha_partitura.pdf"
py -3 maestro/integracoes.py converter "minha_partitura.mscz" "minha_musica.mid"

O MuseScore precisa estar instalado; caso não seja encontrado automaticamente, informe --musescore "C:\Program Files\MuseScore 4\bin\MuseScore4.exe", ajustando para seu computador. Esta interface web ainda não executa diretamente a conversão, para evitar acesso arbitrário ao seu disco.
