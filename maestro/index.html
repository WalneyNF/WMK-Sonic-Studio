Como ouvir no WMK Sonic Studio

  1. Clique em Criar minha música.
  2. Baixe o arquivo .mid.
  3. Abra o WMK Sonic Studio e importe o MIDI em File → Open (ou Ctrl+O).
  4. Escolha um SoundFont ou plugin de instrumento para cada pista, conforme seu ambiente.
  5. Aperte Play, edite as notas e exporte WAV ou OGG para seu jogo.

Limite atual: o Maestro é um módulo web local separado da interface C++ da DAW. Ainda não configura automaticamente plugins ou reproduz áudio neste navegador. Requer Python 3.10+.
